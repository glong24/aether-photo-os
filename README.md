# AETHER // OS — Futuristic Spatial Photo Experience

Interactive spatial photo web application built with React, TypeScript, Tailwind CSS, Framer Motion, and HTML5 Canvas around two personal photos (`public/photos/photo-mirror.jpg` and `public/photos/photo-court.jpg`).

## Features
- Two independently interactive floating photos with drag inertia, magnetic snapping, scroll-wheel zoom, mobile pinch-to-zoom & two-finger rotation, 3D hover tilt, parallax, and double-click reset.
- 6 interactive modes: Free Movement, 3D Space, Overlap, Cinematic, Playground, and Compare (Side-by-Side & Split Curtain).
- Real-time non-destructive visual effects (Neon Glow, RGB Split, Glitch, Blur, Grayscale, Color Filters, Brightness, Contrast, Saturation, Opacity, Shadow, Ambient Lighting).
- Layer Manager, Saved Compositions (`localStorage`), High-Res PNG Screenshot Export, Fullscreen, Hide UI, and optional Web Audio SFX.

## Deployment (Vercel)
- Framework Preset: `Vite`
- Build Command: `npm run build`
- Output Directory: `dist`
